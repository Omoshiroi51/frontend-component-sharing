# 前端组件分享

记录开发中实际用过、值得解释和复用的前端组件。每篇从一个具体问题出发，说明实现思路、关键代码、依赖和使用边界，逐步积累成可以分享的技术笔记。

首批内容来自 **Wisdom Echo（智慧回响）**，整理于 **2026-09-21**。本仓库目前是组件分享笔记，含源码摘录；尚未提供独立安装包或可运行的组件演示。

## 阅读与复用

每篇区分“源码已有行为”和“提取时需要处理的事项”。代码块标明是原始摘录还是接入示意，不能将局部片段当成完整可运行组件。

文中的源码路径均相对 `wisdom-echo` 根目录，来源固定在提交 `deb88bc2d8507f38b9f91d9b68e3662b3c0be0b3`。技术栈、版本和定位方式见[来源记录](docs/sources.md)。笔记可独立阅读，查阅原始实现时再访问原项目。

## 后续补充方式

1. 用[分享笔记模板](docs/component-template.md)记录真实开发场景。
2. 标明源码版本、组件入口、关联样式和实际依赖。
3. 提取可运行示例时，在本仓库内补齐最小依赖、样式和验证说明，再更新目录中的状态。

**本项目的整理和提取只修改「前端组件分享」；`wisdom-echo` 及其他来源项目保持只读。**

本地使用 `main` 分支，按一次组件整理或一次示例提取组织提交。可用以下命令查看内容和历史：

```sh
git status --short --branch
git diff
git log --oneline
```
